Demonstrator der Kanduit UG — alle Daten aus öffentlichen Quellen: Stadt Krefeld (kleinräumige Bevölkerungsdaten, Gebietsgliederung), OGS-Bericht der Stadt Krefeld 2026, Schulministerium NRW (Open Data), Open Data NRW (Kindertageseinrichtungen).
